# Spellwright — Atlas Key Contract (`atlas-key-contract`)

Generated by `scripts/build-assets.py` — do not hand-edit. Owner: Technical Artist.

## Grammar

A frame key is the **art-slot-map JSON path** of the slot (dot-joined, `art` segments dropped) plus `.N` for the frame index — so gameplay binds by data id without a lookup table:

| Pattern | Example | Atlas |
|---|---|---|
| `player.<skin>.{idle,run,hit}.N` | `player.wizzard_m.run.2` | world |
| `enemies.<id>.{idle,move,windup_frame}.N` | `enemies.fire_imp.idle.0` | world |
| `{enemies,bosses}.<id>.{idle,move,windup_frame}.{ring1,ring2}.N` | `enemies.brute.move.ring1.3` — white outline-only overlay (Chebyshev ring 1 / 2, +2 px pad; tint ring1 = first affix token or dark-twist #fdf7ed, ring2 = second affix). Index-synced to the body frame; `pivot` puts its feet on the body's feet (call `setOriginFromFrame()` after `setFrame`) | world |
| `enemies.<id>.{idle,move,windup_frame}_elite.N` | `enemies.brute.move_elite.3` (baked 1 px `#facb3e` outline, +2 px) | world |
| `enemies.<id>.shadow.0`, `bosses.<id>.{idle,move,shadow}.N`, `bosses.<id>.weapon_overlay.<name>.0` | `bosses.archlich.weapon_overlay.boss_lich_staff.0` | world |
| `spells.<id>.projectile.N` | `spells.vortex.projectile.12` | world |
| `enemy_bullets.<element>.<px>.N` | `enemy_bullets.frost.9.1` | world |
| `fx.<id>.N`, `status.<id>.overlay.N` | `fx.hit_ring.3`, `status.burn.overlay.1` | world |
| `tiles.<slot>.N` (+ `@f2`/`@f3` floor variants for doors + pillar) | `tiles.door.states.closed.0@f2` | world |
| `pickups.<id>.N`, `wands.<id>.held.0`, `wands.<id>.drop` | `wands.ember_rod.held.0` | world |
| `authored.<name>` (every 2D-Artist-authored frame, incl. `glow_16/32/64`, `shadow_*`) | `authored.glow_32` | world |
| `icon16.<section>.<id>` (authored 16 px icons, same ids as `icons16.json by_id`) | `icon16.relics.kindling` | world **and** ui |
| `icon32.<section>.<id>` (34×34 7Soul1 icons, LUT-baked) | `icon32.modifiers.homing`, `icon32.reward_kind.shop` | ui |
| `ui.<name>` (every `spellwright_ui.png` frame) | `ui.card_spell_36`, `ui.pip3_fire` | ui (card_*_18, cell_empty_18, badge_20*, pip3_*, chip_7x7 also in world) |
| `ui.<slot>[.hover/.selected/.N]` (Kenney Adventure large tiles) | `ui.panel_dark`, `ui.button.hover`, `ui.banner.1` | ui |
| `font.<body|heading|small>[_outline]` | `font.small_outline` | ui (glyph sheet frame, see Fonts) |
| `util.px2` | 2×2 white, tintable | world + ui |
| `prompt.<xbox|ps|pad>.<id>` (12 px gamepad glyphs; id = controller-prompts §3 atlas id with its first `_` → `.`) | `prompt.ps.cross`, `prompt.pad.dpad_ud` | ui (see Gamepad prompts) |

Deviation from the studio default (kebab-case): keys keep the data ids' `snake_case` and use `.` as the path separator, because the orchestrator contract is *bind by id*. Keys are stable across repacks; a rename is a contract break.

**Frame metadata:** actor frames (player, enemies, elites, bosses, loadout portraits, pillar, crate) carry `pivot` = feet `(0.5, 1.0)`; elite frames carry `(0.5, (h-1)/h)` so the feet stay on the same world point after the outline grows the frame by 1 px. Phaser 4 applies `pivot` on every animation frame change (`customPivot`). 9-slice frames carry `scale9Borders`. Everything else is centred (0.5, 0.5). Every frame in the atlas JSON also carries `source` (pack, cell/rect, LUTs) — Phaser exposes it as `frame.customData.source` — so index-keyed non-animation lists (e.g. `tiles.wall_decor.N` = the slot-map `frames` order: banner red/blue/green/yellow, hole 1/2, goo, goo_base) are traceable.

**Blend reminder (style-guide):** `codemanu` frames (hit_ring*, blink_puff, phase_burst, soul_release, summon_sigil, cast_glyph, shield_overlay, vortex) are greyscale-baked — draw **ADD** and tint with the token. Spell cards `ui.card_spell_*` are white — MULTIPLY-tint by element.

## Tilemap tileset (`tiles_f1`, `tiles_f2`, `tiles_f3`)

Three images with an **identical layout** (floor-palette variants via `L_FLOOR_F2`/`L_FLOOR_F3`). `map.addTilesetImage(name, 'tiles_f1', 16, 16, 1, 2)`. Tile indices + wall autotile lookup: `assets/tiles/tileset-e31334ba.json` (`index`, `wallLookup`).

- Walls: 0x72 `atlas_walls_high` = Godot **3×3-minimal 47-blob** (godot-docs #3316). The mask table was decoded from the canonical reference template (47 unique masks). Bits `N=1 NE=2 E=4 SE=8 S=16 SW=32 W=64 NW=128`; `wallLookup[mask] = [bottomTileIndex, topTileIndex|-1]`. Draw bottom on layer `walls` at the cell, top on layer `wallTops` at the cell above (depth 80).
- Floors: `floor_1..8` (weights in tileset JSON), `floor_atlas_0..48` (0x72 floor sheet; 10–13 = shadow fringe under walls).
- `pit_void` (authored), `edge_down` (pit lip), `floor_spikes_0..3` (reserved).

## Fonts (`font-atlas`, BitmapText from the ui atlas)

Glyph sheets are frames in the `ui` atlas, so UI chrome and text share one texture (no batch break). Load each XML with `load.xml(key, url)`, then after load:

```js
Phaser.GameObjects.BitmapText.ParseFromAtlas(scene, 'font.small_outline', 'ui', 'font.small_outline', 'font.small_outline');
this.add.bitmapText(x, y, 'font.small_outline', 'x2', 8).setTint(0xfdf7ed);
```

| Font key | Source | Native size (render at this or an integer multiple only) | lineHeight / base |
|---|---|---|---|
| `font.body` | Kenney Pixel | 16 px | 12 / 10 |
| `font.body_outline` | Kenney Pixel + 1px #222222 stroke | 16 px | 14 / 11 |
| `font.heading` | Kenney High | 16 px | 14 / 12 |
| `font.heading_outline` | Kenney High + 1px #222222 stroke | 16 px | 16 / 13 |
| `font.small` | Kenney Mini | 8 px | 10 / 8 |
| `font.small_outline` | Kenney Mini + 1px #222222 stroke | 8 px | 12 / 9 |

Glyphs: ASCII 32–126 + `…×·•` from the TTFs; `← → ↑ ↓` are TA-authored cap-height supplements (the Kenney fonts lack U+2190–2193). Fill is white (tint at runtime); `_outline` variants add the 1 px `#222222` 8-neighbour stroke (ui-artwork §text) and advance +1 px.

## Provenance note

0x72 DungeonTileset II files are fetched from a commit-pinned GitHub mirror because itch.io issues only expiring download URLs; four independent mirrors are byte-identical (sha256 recorded in the pack's LICENSE-NOTE.txt). Canonical source: https://0x72.itch.io/dungeontileset-ii (CC0).
